# 💫 About Me:
Lulusan S1 Teknik Informatika dari Universitas Serang Raya dengan pengalaman praktis di bidang *full-stack web development* dan pengelolaan infrastruktur IT. Terbiasa membangun aplikasi web internal dan sistem pendukung operasional bisnis menggunakan PHP Native, MySQL, JavaScript, HTML, dan CSS.<br>Memiliki pengalaman dalam merancang berbagai solusi sistem, seperti website Company Profile hingga sistem pemesanan (*booking system*) internal, sekaligus menangani jaringan kantor, konektivitas LAN/perangkat keras, dan optimasi bandwidth. Berfokus untuk menghadirkan sistem yang andal dan efisien guna mendukung kelancaran alur kerja perusahaan.
